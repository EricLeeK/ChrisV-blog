# 文稿与手记

文稿与项目列表使用紧凑阅读视图，可搜索标题、摘要、标签，并切换封面网格、分类、标签及发布时间排序。筛选条件保存在 URL 中，刷新或分享链接可恢复。

- `/articles`：文稿列表；`/articles/<id>`：文稿详情。
- `/projects`：项目列表；`/projects/<id>`：项目详情，保留体验与源码入口。
- `/random`：手记首页；`/random/<id>`：独立信纸详情。保留已有 `/random` 路径。

## 写文稿和项目

继续编辑 `src/content/articles/*.md` 与 `src/content/projects/*.md`。正文的二、三级标题自动生成阅读目录；项目支持 `website`、`link`；文稿的 `externalUrl` 在详情页显示“打开交互讲义”，原有讲义不变。讲义摘要不标为整篇讲义的阅读时长。

## 写手记

在 `src/content/random/` 新建 Markdown。文件名就是详情地址。日期必填，其余字段可选：

```yaml
---
title: "手记标题"
description: "在往期归档中展示的摘要"
date: 2026-10-27
tags: ["思考"]
# mood: "填写真实心情，或省略"
# weather: "填写真实天气，或省略"
# cover: "/images/your-image.jpg"
---
```

标题缺省时从正文生成短标题，摘要缺省时截取正文。心情、天气与封面不填就不显示。手记按日期排序，首页展示最近一篇，其他篇目按年份归档；期数按日期自动生成（补录历史文章会重排期数）。详情提供相邻手记导航。

## 实现边界

主站背景与主题色在 `src/styles/global.css` 统一定义，`BaseLayout.astro` 为首页、关于、资源及阅读页统一加载 `reading.css` 和 `site.css`。前者维护阅读组件，后者维护首页等共享排版。文稿正文由 `ReadingLayout.astro` 渲染，手记正文由 `NotePaper.astro` 渲染。两套展示共享主题环境，但保留各自详情版式。

有二、三级标题的文稿与项目自动生成 `ReadingOutline.astro` 提纲：桌面在右侧固定，手机在正文前展开；轨迹根据滚动速度产生波浪并回弹，标记沿章节位置移动。停止滚动后动画收敛，页面隐藏时停止；开启系统“减少动态效果”时改为直接定位的静态线条。无需额外动画依赖。

没有添加评论、点赞或阅读量服务。阅读进度仅在当前页面计算，无后端数据。
