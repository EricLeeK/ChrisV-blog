# 首页 UI 评审与方向探索

意图：优化 UI；三档比较阶段，等待方向选择，未修改业务页面。

品类：个人研究与创作博客。首屏任务：认识作者、找到近期文章。参考范围：现有运行页面及其内容；未作外部标杆研究。

现有规范具有辨识度：宋体展示字、暗色背景、暖金点缀、细线分隔可以保留。问题主要是首页内容抵达距离与辅助文字尺度，而非缺少装饰。

实际观察：390px 手机页先呈现介绍、社交、重复作者信息与四个分类，最新文章被推后；分类文案 12px、链接 11px 偏小；长分类标题在桌面四栏中视觉重量失衡。桌面内容区仍有良好的对齐与留白。截图工具确认两种尺寸均无横向溢出、图片加载失败或控制台错误。

建议 B：深色编辑式阅读首页。标题延用品牌字体；正文与操作使用系统字体；暖金只标识主阅读入口。缩短作者介绍，将分类收为目录，首条文章扩大标题。其他列表页沿用同样层级。

C 的完整方向：浅色研究手札；纸白、墨绿、宋体标题、疏朗正文；现有文章封面承担视觉记忆点。后续关键状态包括搜索无结果、筛选、主题切换与手机导航；动效计划为链接反馈、目录选中反馈和列表切换，支持减少动态效果。当前是静态方向小样，未实现或验证动效。

拟精简：首页重复作者介绍；分类描述收起，名称与数量在落地阶段保留。将长分类名称建议改为“博客译藏”，尚未更改原站。
